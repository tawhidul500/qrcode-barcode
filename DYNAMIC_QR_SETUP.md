Dynamic QR mode uses existing tracked links and management SQL. No new SQL or environment variables are required if previous setup is complete. Sign in, enter an HTTP(S) destination, choose Dynamic QR, then download to save automatically. Change the destination using My QR Codes > Edit Content, or load the code in the generator and use Update destination. The downloaded QR stays unchanged. Non-web payloads such as Wi-Fi and contact cards remain static. Redirects depend on keeping this website and database available.
