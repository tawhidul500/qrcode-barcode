CSV import uses the existing saved-code and dynamic-link database setup. No new SQL or environment variables are required. Deploy updated code, sign in, open Import From CSV in the dashboard, download the example, add name and url rows, select a design and Static/Dynamic mode, upload and review, then Generate QR Codes. Maximum UTF-8 CSV file size is 10 MB; maximum 50 rows. The existing account limit of 50 codes includes archived codes. Fix all invalid rows before generating. Saves run one by one. Stop or leaving the page stops after the current row; successfully saved codes remain. Retry resumes failed/remaining rows without rerunning successful rows. To change the design after partial completion, upload again; do not reimport completed rows. Download results individually from My QR Codes.
